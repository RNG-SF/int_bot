BIRTHDAY WEBSITE UNIVERSAL

File:
- index.html  -> struktur halaman
- style.css   -> seluruh tampilan + animasi
- app.js      -> perpindahan halaman, musik, lilin, confetti
- config.js   -> SATU-SATUNYA file yang perlu diubah untuk orang lain
- assets/h.mp3 -> musik

Cara memakai:
1. Masukkan lagu bernama h.mp3 ke assets/
2. Buka config.js
3. Ganti name, nickname, birthday, age, message, dan finalWish.
4. Upload seluruh folder ke hosting/GitHub Pages.

Fitur:
- 6 scene dengan transisi
- background bintang + aurora
- cake bergerak
- api lilin hidup
- lilin bisa disentuh untuk dipadamkan/dinyalakan lagi
- confetti
- musik loop
- tombol musik
- konfigurasi universal untuk orang berbeda
